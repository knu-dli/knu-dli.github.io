- **Title:** 생성형 언어 모델의 평가 연구 경향 (Research Trends in Evaluating Generative Language Models)
- **When:** June 17, 2024, 16:30
- **Where:** Room 112, E3, DGIST School of Electrical Engineering and Computer Science

### Abstract

With the arrival of generative language models, it can seem as if any natural language processing application can be solved simply by asking.
Yet these models have so far been validated under evaluation frameworks for natural language generation that are still immature.
This talk introduces recent efforts to evaluate the performance of generative language models following their rapid progress.
In particular, it covers how to evaluate them on two major application areas — Korean dialogue and code generation — and briefly discusses the current limitations of generative language models.
